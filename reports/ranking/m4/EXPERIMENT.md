# M4 frozen experiment protocol (before development scoring)

Hypothesis: semantic matching of natural user sentences to O*NET tasks may recover paraphrases missed by lexical retrieval. It may also reward explicit dislikes, contradictions, and familiarity statements; quality gains are not assumed. No evidence filtering, stance weighting, threshold tuning, or new fusion weighting is introduced.

Pin: `sentence-transformers/all-MiniLM-L6-v2`, revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. CPU float32, one thread, seed 425, normalized 384-dimensional embeddings, maximum 256 wordpieces, batch size 32. The same local snapshot/encoder handles task statements and user sentences. No training. Sources: [model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/tree/1110a243fdf4706b3f48f1d95db1a4f5529b4d41), [SentenceTransformer API](https://sbert.net/docs/package_reference/sentence_transformer/model.html), [FAISS exact search](https://github.com/facebookresearch/faiss/wiki/Getting-started).

Only tasks belonging to the unchanged eligible 378-occupation pool are indexed. Preserve task text verbatim; sort `(occupation code, task ID)` for a stable mapping. Build normalized embeddings and FAISS IndexFlatIP once. Cache metadata includes model file hashes, revision, task CSV/mapping hashes, pool, parameters, package versions, artifact hashes, build time and bytes. Runtime refuses stale/corrupt caches and never re-embeds the task corpus.

Registered variant: `minilm@mean_tasks_v1`. Split accumulated user utterances on `. ! ?` and newline boundaries, retaining natural wording, negation, repetition and case; omit punctuation/whitespace-only spans. No BM25 preprocessing or sentence deduplication. For each sentence, exhaustively search all tasks, take the best task similarity per occupation, then average these per-sentence maxima. Keep negative similarities; no relevance threshold is tuned. Missing-task occupations have no dense rank. Empty text gives no dense signal. Tie-break by occupation code. Return at most three task matches per occupation, chosen by maximum similarity across query sentences with task-ID tie-breaking, marked provisional even for dislikes.

Conditions: structured-only, BM25-only, structured+BM25 controls; dense-only, structured+dense, BM25+dense, and structured+BM25+dense treatments. Identical 60 development/oracle snapshots, profile IDs, candidate pool, M1/M3 parameters, equal-weight RRF k=60 and six M2 metrics. No held-out scoring/tuning. Structured oracle vectors are privileged synthetic information; this is not actual-tracker or end-to-end probing evaluation.

Save every successful run and centralized history row. Compare paired metrics/profile shifts with seeded 2,000-resample bootstrap intervals. Record cache build/size and preloaded query median/p95. Repeat all four dense conditions against cache reloads with fixed inputs (float-score tolerance 1e-6; ranks/metrics exact). Inspect gains and regressions, including dislikes and both genuine/misleading familiarity. Default adoption is decided from the measured comparison; keep prior controls intact. Stop before M5.
