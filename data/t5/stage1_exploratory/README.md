# Provisional career question dataset

600 AI-authored, template-expanded examples, generated by
`python -m training.build_data`. There are 60 scenarios (10 activities per RIASEC
type), with 10 renderings each: 3 CLARIFY, 2 PROBE, 2 CHALLENGE and 3 ABSTAIN
(one retry of each underlying question action).

The seed-42 split assigns entire activity scenarios before expanding them:
420 train, 90 validation, 90 test. Each split includes every type and action.
Input strings and scenario IDs do not cross splits. Generic response templates
are intentionally shared across splits; these splits test new activity contexts,
not general linguistic novelty or real-user performance. The three style labels
provide modest wording control, not a guarantee of distinct generations.

Sources: original synthetic activity scenarios and paraphrase patterns authored
for this repository from the supplied project descriptions and existing question
templates. No O*NET task statements or external dialogue dataset were copied.
No project evaluation profiles, participant transcripts, or real personal data
are included. `human_reviewed` is false throughout: a team member should review
wording, RIASEC alignment and action intent before treating this as final data.
Any training on this version is an exploratory experiment.

Input is `career question: ` followed by a JSON object containing the selected
action, full type name, reference question, relevant source context, retry flag,
previous question and requested style. Target is only the follow-up question.
Exact source quotations and the ABSTAIN acknowledgement are inserted by Python.
CHALLENGE explicitly asks the user to choose between statements, following the
proposal. Allowing a mixed/contextual answer is deferred.

CLARIFY uses no user context. PROBE uses its familiarity sentence. CHALLENGE uses
both statements, with their order reversed in half of scenarios. No whole-history
retrieval text is sent to T5. ABSTAIN retains the underlying action and context.

Review JSONL in a text editor; retain `group` when editing or splitting examples.
Regenerating overwrites the three JSONL files, so preserve reviewed edits first.
